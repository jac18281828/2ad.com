## Turn it on

The pass runs under the ray tracer. Make three edits to the `vase.rib` that Try it on the [gman page](/gman.html) downloads:

1. Add one line under `PixelSamples 2 2`:

    ```
    Option "render" "string indirect" ["radiosity"]
    ```

2. Set `Ka` equal to `Kd` on each `Surface`.
3. Delete the `ambientlight`, `LightSource "ambientlight" 1 "intensity" [0.38]`, which the pass replaces.

Then render it as before:

```sh
gman -r gmanraytracer vase.rib
```

`Option "radiosity" "float elementsize"` sets the patch size, an eighth of the scene's largest side by default.

## How it works

Under `-r gmanraytracer`, the radiosity pass does four things:

- It dices the scene into patches.
- It solves the diffuse light bouncing between the patches by progressive refinement, and passes light through translucent surfaces attenuated by `1 - Os`.
- It hands each shaded point its indirect irradiance. `ambient()` adds it to the ambient lights, so each surface weights it by its own `Ka`, colour bleeding included.
- It gives reflected and refracted hits the same irradiance.

Radiosity goes back to Wallace, Cohen and Greenberg (1987), who joined it to ray tracing in a two-pass method. BMRT offered the same idea as `-radio`.

## A stub since 2002

The revival began with a `gmanradiosity` renderer that was present, non-functional and built `OFF`. 1.0 deletes it. `libgmanradiosity.so` becomes `libradiosity.so`, which the ray tracer loads as a pass by name, and the plugin builds by default, so every download carries `libradiosity.so`.
